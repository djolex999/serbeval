# serbeval v0.1 (+v0.2) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Serbian-language LLM evaluation benchmark — versioned datasets, lm-evaluation-harness task configs, candidate-generation and self-consistency tooling — fully tested, typed, and linted, ready for the maintainer's human verification pass.

**Architecture:** Python package (`src/serbeval/`) holding the item schema, dataset validation, and Claude-API tooling. Datasets live as JSONL under `data/<task>/`. lm-eval task YAMLs live under `lm_eval_tasks/` and load the local JSONL via the HF `json` loader; all tasks are `generate_until` + regex answer extraction (works with chat APIs that expose no logprobs). Results land under `results/`.

**Tech Stack:** Python 3.13, lm-eval==0.4.12 (pinned harness), anthropic SDK, pydantic v2, pytest, mypy (strict), ruff.

**Constraints discovered up front (logged in DECISIONS.md):**
- No ANTHROPIC_API_KEY / `ant` profile on this machine → every API-touching feature is built + mock-tested; live runs are documented TODOs.
- Seed items are authored in-session via multi-agent author/verify workflows; all items keep `verified: false` until the maintainer's human pass.

### Task 2: Item schema

**Files:** `src/serbeval/schema.py`, `tests/test_schema.py`

```python
class EvalItem(BaseModel):
    id: str                       # "<task-slug>-<category>-NNNN"
    task: str
    category: str
    question: str                 # Serbian, self-contained
    choices: list[str]            # exactly 4, unique
    answer_index: int             # 0..3
    explanation: str
    script: Literal["cyrillic", "latin"]
    pair_id: str | None = None    # cyrillic_agreement pairs
    source: str                   # "handwritten-claude" | "generated-claude-<model>"
    verified: bool = False
    license: str = "CC-BY-4.0"
```

- [ ] TDD: failing tests for valid item, wrong choice count, out-of-range answer_index, duplicate choices, empty question
- [ ] Implement with pydantic validators; run tests; commit `feat: add EvalItem schema`
